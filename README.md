# АвтоЖурнал

Учёт заправок и расходов на авто. Несколько машин, синхронизация с Google Диском
(папки «АвтоЖурнал / машина / файл»), работает на телефоне и компьютере, ставится как приложение.

## Публикация на GitHub Pages
1. Создайте репозиторий на github.com (например, `avto`).
2. Загрузите в корень репозитория **все файлы из этой папки** (`index.html`, `manifest.json`, `sw.js`, `icons/`, `.nojekyll`).
3. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)` → Save.
4. Через минуту адрес будет таким: `https://ВАШ-ЛОГИН.github.io/avto/`

## Подключение Google Диска
1. Google Cloud Console → проект → включить **Google Drive API**.
2. Google Auth Platform: экран согласия (External, режим Testing), свой Gmail добавить в Test users.
3. Clients → Create client → Web application. В «Authorized JavaScript origins» добавьте
   `https://ВАШ-ЛОГИН.github.io` (без пути и без `/` на конце).
4. Скопируйте Client ID → в приложении: Настройки → Google OAuth Client ID → «Синхронизировать».

## Установка как приложение
- Android (Chrome): меню → «Установить приложение».
- iPhone (Safari): «Поделиться» → «На экран Домой».
- Компьютер (Chrome/Edge): значок установки в адресной строке.

## Обновление
Замените файлы в репозитории. Service worker сначала берёт свежую версию из сети,
поэтому обновление приходит при следующем открытии с интернетом.

## Данные
Хранятся в браузере устройства и в вашей папке на Google Диске. В репозитории данных нет.
